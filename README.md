# Dislite roadmap

What's shipped and what's planned for [Dislite](https://dislite.xyz), a chat and community app
built and maintained by one developer.

## Shipped

- Groups with channels
- Direct messages
- Voice chat
- Real-time presence
- Profiles with bio, custom status, avatar, and banner
- Friend requests and blocking
- Clips and file sharing

## In progress / planned

- Deeper moderation tools for group admins
- Improved reliability for real-time chat under flaky connections
- More granular notification controls
- Mobile-friendly polish passes

## Suggest something

Open an [issue](../../issues) with a feature idea or a bug. Priorities shift based on what
people actually ask for, not an internal backlog nobody sees.
